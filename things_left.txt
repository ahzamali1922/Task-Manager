CURRENT LEARNING ROADMAP
------------------------

1. USER AUTHENTICATION 🔐
   Learn:
   - User registration   #Done
   - Login
   - Logout
   - authenticate()
   - login()
   - logout()
   - request.user
   - is_authenticated
   - @login_required
   - Password handling

   Goal:
   Build a working account system where users can
   register, login and logout.


2. USER-SPECIFIC TASKS 👤
   Learn:
   - request.user
   - Connecting Task to the logged-in user
   - Filtering tasks by user
   - Creating tasks for the current user

   Example:
       Task.objects.filter(user=request.user)

   Goal:
   Each user sees and manages only their own tasks.


3. CRUD OPERATIONS 📝
   Learn:
   - CREATE
   - READ
   - UPDATE
   - DELETE
   - ORM queries
   - Views
   - URLs
   - Templates
   - Redirects

   Build:
       Task List
       Task Detail
       Create Task
       Edit Task
       Delete Task

   Goal:
   Build the core Task Manager functionality.


4. PERMISSIONS & SECURITY 🛡️
   Learn:
   - Authentication vs Authorization
   - @login_required
   - Object ownership
   - Preventing access to other users' tasks
   - CSRF
   - Basic Django security

   Goal:
   Make sure users can only access and modify
   resources they are allowed to use.


5. FORMS & MODEL FORMS 📋
   Learn:
   - forms.py
   - Form
   - ModelForm
   - Form validation
   - is_valid()
   - cleaned_data
   - GET vs POST
   - CSRF protection

   Goal:
   Handle user input properly using Django forms.


6. URL ROUTING 🔗
   Learn:
   - urls.py
   - path()
   - include()
   - URL parameters
   - URL names
   - namespaces
   - {% url %}

   Goal:
   Understand how URLs connect the browser to Django views.


7. VIEWS ⚙️
   Learn:
   - request
   - render()
   - redirect()
   - HttpResponse()
   - GET / POST
   - Passing context to templates

   Goal:
   Understand how Django handles requests and
   generates responses.


8. TEMPLATES 🎨
   Learn:
   - Template variables
   - for loops
   - if statements
   - Template filters
   - extends
   - blocks
   - Template inheritance

   Goal:
   Display dynamic database information in HTML.


9. DJANGO MESSAGES 💬
   Learn:
   - messages.success()
   - messages.error()
   - messages.warning()
   - messages.info()

   Goal:
   Give users feedback after actions.


10. STATIC FILES 🎨
    Learn:
    - static/
    - CSS
    - JavaScript
    - {% load static %}
    - STATIC_URL

    Goal:
    Style and improve the frontend.


11. TASK MANAGER FEATURES 🚀
    Add features such as:
    - Search
    - Filtering
    - Sorting
    - Categories
    - Priority filtering
    - Due dates
    - Pagination
    - Dashboard
    - Statistics

    Goal:
    Turn the basic CRUD application into a useful
    real-world Task Manager.


12. TESTING 🧪
    Learn:
    - TestCase
    - Model tests
    - View tests
    - Form tests
    - Authentication tests
    - Permission tests

    Goal:
    Make sure the application works correctly
    and securely.


13. DEPLOYMENT 🌍
    Learn:
    - DEBUG=False
    - ALLOWED_HOSTS
    - Environment variables
    - Production database
    - Static files
    - WSGI / ASGI
    - Deployment
    - Production security

    Goal:
    Deploy the Task Manager so it can be accessed online.
