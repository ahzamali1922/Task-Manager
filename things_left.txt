============================================================
1. DJANGO PROJECT & APP STRUCTURE ✓
============================================================

Learn:
- What a Django project is
- What a Django app is
- manage.py
- settings.py
- apps.py
- project vs app

Project structure:

    config/       -> project configuration
    accounts/     -> user-related functionality
    task/         -> task-related functionality
    manage.py     -> Django command-line utility

Goal:
Understand how Django projects and apps are organized.

- auto_now_add

Your main models:

    Task
    Category

      +---- Task

============================================================

6. URL ROUTING
============================================================

Learn:
- urls.py
- path()
- include()
- URL parameters
- URL names
- namespace
- Connecting URLs to views

Example:

    /tasks/
       |
       v
    task_list()

Goal:
Understand how Django decides which view should handle
a browser request.

Flow:

    Browser
       ↓
    URL
       ↓
    urls.py
       ↓
    View


============================================================
7. VIEWS
============================================================

Learn:
- Django views
- request object
- GET requests
- POST requests
- render()
- redirect()
- HttpResponse()
- Passing data to templates

Example:

    def task_list(request):
        tasks = Task.objects.all()
        return render(
            request,
            'task/task_list.html',
            {'tasks': tasks}
        )

Goal:
Learn how Django processes requests and creates responses.


============================================================
8. TEMPLATES
============================================================

Learn:
- Django templates
- Template variables
- for loops
- if statements
- template filters
- extends
- blocks
- url template tag

Example:

    {{ task.title }}

    {% for task in tasks %}
        {{ task.title }}
    {% endfor %}

Learn template inheritance:

    base.html
       |
       +-- task_list.html
       +-- task_detail.html
       +-- task_form.html

Goal:
Display dynamic database data on HTML pages.


============================================================
9. DJANGO ORM / DATABASE QUERIES
============================================================

Learn how to interact with the database using Python
instead of writing SQL directly.

Important queries:

    Task.objects.all()

    Task.objects.filter(...)

    Task.objects.get(...)

    Task.objects.create(...)

    Task.objects.update(...)

    Task.objects.delete(...)

Also learn:

- QuerySets
- filtering
- ordering
- relationships
- get_object_or_404()

Goal:
Be comfortable reading, creating, updating and deleting
database objects using Django ORM.


============================================================
10. CRUD OPERATIONS
============================================================

CRUD = Create, Read, Update, Delete

CREATE:
    Create a new task.

READ:
    Display tasks.

UPDATE:
    Edit an existing task.

DELETE:
    Remove a task.

Pages/features:

    Task List
    Task Detail
    Create Task
    Edit Task
    Delete Task

Goal:
Build the core functionality of the Task Manager.

Flow:

    URL
     ↓
    View
     ↓
    ORM
     ↓
    Database
     ↓
    Template
     ↓
    Browser

============================================================
13. USER-SPECIFIC TASKS
============================================================

Connect authentication with your Task model.

Each task belongs to a user.

Example:

    Alice
      ├── Task A
      ├── Task B
      └── Task C

    Bob
      ├── Task D
      └── Task E

Alice should only see Alice's tasks.
Bob should only see Bob's tasks.

Learn:

    request.user

    Task.objects.filter(user=request.user)

Goal:
Build a real multi-user Task Manager.


============================================================
14. PERMISSIONS & SECURITY
============================================================

Learn:
- Authentication vs authorization
- Login protection
- Object ownership
- Preventing users from accessing other users' tasks
- CSRF
- Basic Django security practices

Example:

User should NOT be able to edit:

    /tasks/25/

if Task #25 belongs to another user.

Goal:
Make sure users can only access and modify
what they are allowed to.
